A chatbot answers. An agent acts. Welcome to Agent School — lesson thirteen.
Everything so far was about a model that talks. Now we give it a job.
Ask a chatbot: "find me a cheap flight to Dubai." It tells you how to search.
Ask an agent the same thing… and it searches, compares prices, and comes back with options.
An agent is an AI model plus three things: tools it can use, a goal to reach, and a loop to keep going until it's done.
The model is still the brain. It still predicts. But now its predictions decide actions: search this, open that, check again.
More power means more risk. An agent that can act can also act wrong. That's why later lessons cover guardrails.
Remember: chatbot equals talk. Agent equals model, tools, goal, and a loop.
