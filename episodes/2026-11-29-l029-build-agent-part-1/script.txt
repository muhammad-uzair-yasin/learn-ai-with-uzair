Let's build a real AI agent. Right now. Welcome to Agent School — lesson twenty-nine.
Our agent's job: answer questions about the weather and do the math. Two tools.
Step one: the tools. A function called get_weather. A function called calculate. Each with a short description the model can read.
Step two: the system prompt. "You are a helpful assistant. Use tools when you need facts or math."
Step three: the loop. Send the conversation and the tool list to the model. If it asks for a tool — run it, add the result, and loop again. If it answers — we're done.
Step four: a stop rule. Maximum five steps.
That's the whole agent. Around thirty lines of code. No framework.
Remember: tools, prompt, loop, limit. That's an agent you can build tonight.
